Sea Society Ibiza — Book here event tracking

Reference for the marketing / analytics team. Covers what the site currently fires, how to verify it in GA4, and how to wire the event through Google Tag Manager if you later add a GTM container on top.

1. What's wired in code

All "Book here" CTAs across the public site call a single helper, trackBookHereClick() (lib/analytics.ts), which fires a custom GA4 event via the existing gtag bootstrap. No further front-end work is needed — it works on every deploy.

Event payload

FieldTypeExampleNotes
event_name string book_here_click The only event name we send for this conversion.
placement string boat_detail_hero Which button on which surface (see taxonomy below).
page_path string /fleet/dr-no-pershing-6x Read live from window.location.pathname.
device enum mobile | tablet | desktop Bucketed by viewport: <768px / <1100px / ≥1100px.
boat string? dr-no-pershing-6x Only set on boat-specific surfaces.
experience string? day-trips Only set on experience-specific surfaces.
transport_type string beacon Survives the new-tab navigation to WhatsApp.

2. Verify the event fires 5 min

  1. Open the live site in Chrome, accept the cookie banner (Analytics opt-in required).
  2. Open DevTools → Network → filter for g/collect or gtag.
  3. Click any "Book here" button. You should see a request like: 
    en=book_here_click&placement=boat_detail_hero&page_path=/fleet/dr-no-pershing-6x&device=desktop&boat=dr-no-pershing-6x
  4. In GA4 → Admin → DebugView, select the stream and watch live. The book_here_click event lands within ~5s with the parameter pills visible.

Troubleshooting: nothing fires → cookie consent declined. Re-open the banner and accept Analytics.

3. Register custom dimensions in GA4 2 min

GA4 collects the params automatically, but won't display them in reports until you register them as custom dimensions.

GA4 → Admin → Custom definitions → Custom dimensions → Create. One per row:

Dimension nameScopeEvent parameter
Book placementEventplacement
Click deviceEventdevice
Boat slugEventboat
Experience slugEventexperience
Page pathEventpage_path

Custom dimensions take up to 24h to start populating in Explorations and reports. Real-time + DebugView see them immediately.

4. Mark as conversion 1 min

  1. GA4 → Admin → Events → find book_here_click in the list (appears after the first real fire).
  2. Toggle Mark as conversion ON.
  3. Conversion now appears in Reports → Engagement → Conversions, sliceable by source/medium/campaign.

5. Conversion dashboard 5 min

GA4 → Explore → Free form:

  • Rows: Book placement (or Page path).
  • Columns: Click device.
  • Values: Event count for book_here_click.

6. (Optional) Wire through Google Tag Manager

The site fires events directly via gtag, so GA4 works without GTM. Add GTM only if you want to layer a Meta Pixel Lead, LinkedIn conversion, TikTok pixel, etc. without re-deploying code.

6a. Install GTM (one-time)

  1. tagmanager.google.com → create a Web container for seasocietyibiza.com.
  2. You get two snippets — head and body. Paste them into app/layout.tsx via next/script: 
    <Script id="gtm" strategy="afterInteractive">
{`(function(w,d,s,l,i){w[l]=w[l]||[];w[l].push(
  {'gtm.start': new Date().getTime(), event:'gtm.js'});
  var f=d.getElementsByTagName(s)[0], j=d.createElement(s);
  j.async=true; j.src='https://www.googletagmanager.com/gtm.js?id='+i;
  f.parentNode.insertBefore(j,f);
})(window,document,'script','dataLayer','GTM-XXXXXXX');`}
</Script>
  3. Replace GTM-XXXXXXX with your container ID.

6b. Create a Custom Event trigger

  1. GTM → Triggers → New.
  2. Trigger Type: Custom Event.
  3. Event name: book_here_click (exact match).
  4. Fires on: All Custom Events.
  5. Name the trigger CE — Book here click. Save.

6c. Create Data Layer Variables for each parameter

For each parameter you want to use in tags:

  1. GTM → Variables → User-Defined → New.
  2. Variable Type: Data Layer Variable.
  3. Data Layer Variable Name: one of: placement, device, boat, experience, page_path.
  4. Name the variable DLV — placement (etc.). Save.
  5. Reference in tags as {{DLV — placement}}.

6d. Example tag: Meta Pixel "Lead"

  1. GTM → Tags → New → Tag Type: Custom HTML.
  2. Paste: 
    <script>
  fbq('track', 'Lead', {
    content_name: '{{DLV — placement}}',
    content_category: '{{DLV — device}}',
    source_url: '{{Page URL}}'
  });
</script>
  3. Triggering: CE — Book here click.
  4. Save → Submit → Publish.
